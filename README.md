# 🍴 My Restaurant

A restaurant web application developed to provide a seamless experience for customers to explore restaurant offerings and interact with restaurant services through a modern web interface.

## 🌐 Live Demo

https://my-restaurant-2.onrender.com

> ⚠️ The application is hosted on Render. Initial loading may take a few moments if the server is inactive.

- Modern user interface
- Responsive design

- Interactive user experience
- Full-stack web application architecture
